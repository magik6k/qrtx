qrtx

GitHub

Scan two QR codes with your phone, get a direct encrypted pipe between two computers. P2P over iroh.

  1. 1
    First computer
    scan the QR code qrtx prints
  2. 2
    Second computer
    scan the other one

how it works

      

        
        
      

      
    
        
  • QR code = endpoint key + relay + one-time secret, in the URL #fragment (never sent to the server)
    • 
        
  • phone runs iroh (wasm), dials each computer, proves it saw the code with the secret
    • 
        
  • computers connect directly, NAT hole-punched, relay as fallback; each accepts only the introduced key
    • 
        
  • this site is static files
    • 
      

    


    

      
usage

      
Run on both machines, scan both codes. Linux / macOS, x86-64 / arm64.


      
send a file (no install)

      
sender
curl -fsSL https://qrtx.lol/send | sh -s -- backup.tar

      
receiver
curl -fsSL https://qrtx.lol/recv | sh -s -- backup.tar

      
installed: qrtx send f / qrtx recv f, or pipes: tar c . | qrtx / qrtx | tar x


      
ssh, no open ports

      
server
curl -fsSL https://qrtx.lol/sshd | sh

      
laptop
curl -fsSL https://qrtx.lol/ssh | sh -s -- me@myserver

      
one session, then the server side exits. Your own ssh does auth and host-key checks; myserver is just the known_hosts name.


      
forward a tcp port

      
server
qrtx listen-tcp --host localhost:5432

      
laptop
qrtx connect-tcp --addr 127.0.0.1:5432


      
install

      
install
curl -fsSL https://qrtx.lol/install | sh

      
run once
curl -fsSL https://qrtx.lol/run | sh -s -- listen-tcp --host localhost:22

      
scripts fetch the binary for your platform into ~/.cache/qrtx, sha256-checked
